# Zen Mode Supreme Obsidian plugin

[Obsidian](https://obsidian.md) plugin that hides all UI so you can focus on writing.

[![Washing your code. A book on clean code for frontend developers](https://sapegin.me/images/washing-code-github.jpg)](https://sapegin.me/book/)

## What this plugin does

Hides tabs, filename header, status bar, and so on, as well as makes a few adjustments such as adding extra whitespace and deemphasizes tags and properties.

## Motivation

I [don’t deal well with distractions](https://sapegin.me/blog/adhd-focus/), so I always try to minimize them. The Obsidian [Hider](https://github.com/kepano/obsidian-hider) plugin is great, but sometimes I want to hide even more, so I can focus on writing.

This plugin was inspired by the [iA Writer](https://ia.net/writer).
